# 🎲 CrystalRoll Bot

Телеграм-бот с гача-механикой. Бросай кристаллы, собирай коллекцию!

## 🚀 Как запустить

### 1. Установи зависимости
```bash
pip install -r requirements.txt
```

### 2. Получи токен бота
- Открой Telegram → @BotFather
- Напиши /newbot
- Следуй инструкциям
- Скопируй токен

### 3. Вставь токен
Открой файл `.env` и замени `ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER` на свой токен

### 4. Запусти
```bash
python bot.py
```

### 5. Напиши боту
В Telegram найди своего бота и напиши /start

## 🎮 Как играть
- /start — начать игру
- /balance — проверить монеты
- /collection — посмотреть коллекцию
- /daily — получить ежедневный бонус (+50 монет)
- Нажми кнопку ROLL чтобы бросить кристалл!

## 💎 Редкости кристаллов
- ⚡ Мифический — 1/10000
- 🔥 Легендарный — 1/1000
- 💜 Эпический — 1/100
- 💎 Редкий — 1/20
- 💚 Необычный — 1/5
- 🔵 Обычный — 1/2
